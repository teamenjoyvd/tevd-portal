Radius Bench

Every surface in the portal, rendered live at whatever corner radius you dial in. The sliders start at the shipped values — 8px containers, 4px controls. Move them to see what a change would actually do before you make it.

The fact this tool exists to make visible. CSS clamps corner radii when the two radii on a side exceed that side's length (CSS Backgrounds 3 §5.5): every radius scales down by the same factor. For a uniform radius the rendered corner is min(r, width/2, height/2).

A status badge is 19px tall. At 16px it renders at 9.5px — exactly half its height, which is a capsule. At 12px it is still a capsule. Nothing at or above ~9px changes that badge at all. This is why a single site-wide radius cannot work, and why the system has two tiers.

The shipped system

Why 8 and 4

Two tiers, held at 2:1

Decided in 2608-DEV-740 after the single-16px rule failed visual review.

One value could not work

A single radius cannot serve a 200px card and a 19px badge, because the badge clamps. The original rule produced 16px cards and capsule-shaped pills, which is precisely what it was written to prevent.

Nothing clamps at 8 / 4

Both values sit below half the height of the shortest element in their tier, so every surface renders the exact number set. Dial the sliders above 9px and watch the control specimens flip to “capsule”.

The 2:1 gap is the system

A badge inside a card needs a visibly tighter corner than the card, or the two tiers read as noise rather than hierarchy. If you change these values, keep the ratio — and keep the control value under half the shortest badge.

/* styles/brand-tokens.css */ --radius: 8px; /* containers → rounded-container */ --radius-control: 4px; /* controls → rounded-control */ /* app/globals.css @theme — legacy landing zone, not a scale */ --radius-sm: 2px; --radius-md: var(--radius-control); --radius-lg: var(--radius-control); --radius-xl: var(--radius-control); --radius-2xl: var(--radius-container);
Specimens mirror the token values in styles/brand-tokens.css; update them here if those change. Heights are measured in your browser, so they reflect real layout, not estimates.
